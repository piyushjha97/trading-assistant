# Repository working rules

- Make all application-code changes on an `ft/*` feature branch. Never write or commit application code directly on `main`.
- Before changing code, check the current branch and switch to or create an appropriate `ft/*` branch if needed.
- Keep the user's `main` branch as the integration branch; push feature work to its feature branch for review or merge.
- Do not include secrets, local environment files, or generated artifacts in commits.
